# Fluent Emoji WebP

Microsoft's animated [Fluent Emoji](https://github.com/microsoft/fluentui-emoji-animated) as animated WebP, 128 px at 24 fps, for image loaders that play WebP but not APNG.

Files are named by code point, lowercase hex joined with `-`, without zero padding: `1f600.webp`, `2764-fe0f.webp`, `1f44d-1f3fd.webp`. Each was converted from the APNGs in [bignutty/fluent-emoji](https://github.com/bignutty/fluent-emoji) at commit `0afbb62`.
